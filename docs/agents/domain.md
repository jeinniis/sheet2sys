# Domain doc layout

Single-context project — one domain, no bounded-context split.

- `CONTEXT.md` at the repo root holds the domain vocabulary (Note, Case,
  Draft, Diagram, Category, Tag, Backlink, Author) and the fixed six
  categories.
- `docs/adr/000N-title.md` holds Architecture Decision Records, numbered
  sequentially starting at `0001`. Next available number: `0009`.
