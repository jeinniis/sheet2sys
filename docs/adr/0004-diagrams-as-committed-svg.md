# Diagram เก็บเป็นไฟล์ SVG ในโปรเจกต์ ไม่เรนเดอร์ตอนผู้ใช้เปิดเว็บ

ทุกชิ้นในคลังมีไดอะแกรมประกอบ เราเก็บเป็นไฟล์ SVG ที่เป็นข้อความในโปรเจกต์
ผู้อ่านจึงไม่ต้องโหลด JavaScript ใดๆ เพื่อดูไดอะแกรม และ build ไม่ต้องพึ่ง dependency เพิ่ม

ทางเลือกที่ปฏิเสธ: (1) Mermaid ทำงานฝั่งผู้ใช้ ซึ่งยัด JS ราว 1MB ให้ผู้อ่านทุกคน ขัดกับข้อกำหนด
เรื่องความเร็วโดยตรง (2) Mermaid แปลงเป็น SVG ตอน build ซึ่งให้ผลลัพธ์ดีเท่ากันสำหรับผู้อ่าน
แต่ต้องติดตั้ง headless browser ในขั้นตอน build ทำให้มีของที่พังได้เพิ่มขึ้นหนึ่งอย่าง
ข้อ (2) ยังเปิดทางไว้ให้เติมภายหลังได้โดยไม่ต้องรื้อของเดิม หากพบว่าการเขียน SVG เองช้าเกินไป
