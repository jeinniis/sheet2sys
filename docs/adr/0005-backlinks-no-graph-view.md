# มี Backlink แต่ไม่มี Graph View

ผู้เขียนลิงก์ข้ามของในคลังด้วยไวยากรณ์ [[...]] ในไฟล์ Markdown ระบบคำนวณ Backlink
ทั้งหมดตอน build แล้วแสดงท้ายของแต่ละชิ้น โดยผู้อ่านไม่ต้องโหลด JavaScript

เราปฏิเสธ graph view แบบที่เห็นในเครื่องมือจดโน้ต แม้เจ้าของเว็บจะอยากได้ เพราะมันต้องใช้
ไลบรารีวาดกราฟขนาด 100–200KB ซึ่งขัดกับข้อกำหนดเรื่องความเร็วและความง่ายในการดูแล
และในทางปฏิบัติแทบไม่มีใครใช้มันค้นหาเนื้อหาจริง ทางออกคือผู้เขียนเปิดโฟลเดอร์เนื้อหาด้วย
Obsidian เมื่อใดก็ได้เพื่อดู graph view ของตัวเอง โดยที่เว็บสาธารณะไม่ต้องแบกต้นทุนนั้น

นอกจากคุณค่าต่อผู้อ่านแล้ว การลิงก์ข้ามเนื้อหายังเป็นวิธีหลักที่ทำให้เครื่องมือค้นหาเข้าใจว่า
เว็บนี้เชี่ยวชาญด้านใด จึงเป็นฟีเจอร์ที่คุ้มที่สุดในเว็บนี้
