# ของในคลังมีสองประเภทเท่านั้น: Note และ Case

Note คือความรู้ชิ้นเดียวจบ Case คือเรื่องเล่าของระบบที่สร้างจริงซึ่งมีโครงสร้างต่างออกไป
(ปัญหา → สิ่งที่ลอง → สิ่งที่พัง → ผลลัพธ์) และทำหน้าที่เป็นหลักฐานความสามารถของผู้เขียน

เราปฏิเสธทั้งการมีประเภทเดียว (เพราะจะโชว์ Case ให้เด่นในฐานะพอร์ตไม่ได้) และการมีสามประเภทขึ้นไป
(เพราะทุกประเภทที่เพิ่มคือการตัดสินใจที่ผู้เขียนต้องทำก่อนเริ่มเขียนทุกครั้ง ซึ่งเป็นแรงเสียดทาน
ที่ทำลายเป้าหมาย 10 ชิ้นต่อเดือน) ความแตกต่างที่ละเอียดกว่านั้นให้ใช้ Tag รับไป
