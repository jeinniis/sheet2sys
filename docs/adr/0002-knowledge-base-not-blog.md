# เว็บนี้เป็นคลัง ไม่ใช่บล็อก และ URL ห้ามมีวันที่

ของในคลังคือสิ่งที่มีชีวิต ผู้เขียนกลับมาแก้ไขและเพิ่มเติมได้ตลอด เราจึงจัดของตามหัวข้อไม่ใช่ตามวันที่
แสดง "อัปเดตล่าสุด" แทน "เผยแพร่เมื่อ" และ URL ต้องไม่มีวันที่อยู่ในเส้นทาง

เหตุผล: เนื้อหาทั้งหมดมาจากประสบการณ์ทำงานของผู้เขียนซึ่งจะลึกขึ้นทุกปี ถ้าโครงสร้างเป็นบล็อก
ผู้เขียนจะถูกบังคับให้เขียนชิ้นใหม่ทั้งที่ควรแค่แก้ของเดิม และ Google ให้น้ำหนักกับหน้าที่ถูกดูแล
ต่อเนื่องมากกว่าหน้าที่ถูกทิ้งร้าง การใส่วันที่ใน URL เป็นการตัดสินใจที่ย้อนกลับยากที่สุดในเว็บเนื้อหา
เพราะการเปลี่ยนทีหลังคือการทิ้งอันดับที่สะสมมาทั้งหมด
