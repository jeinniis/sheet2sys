# เนื้อหาอยู่ในไฟล์ Markdown ในโปรเจกต์ ไม่ใช่ Notion

เนื้อหาเดิมกระจายอยู่ใน Notion, Google Drive และ Figma แต่เราเลือกย้ายออกจาก Notion
ครั้งเดียวแบบถาวร แล้วให้ไฟล์ Markdown ในโปรเจกต์เป็นแหล่งข้อมูลจริงเพียงแห่งเดียว

ทางเลือกที่ปฏิเสธคือให้เว็บดึงเนื้อหาจาก Notion API ตอน build ซึ่งฟังดูสะดวกกว่าเพราะไม่ต้องย้ายของ
แต่รูปภาพใน Notion เสิร์ฟผ่าน signed URL ที่หมดอายุในราวหนึ่งชั่วโมง ทำให้ต้องเขียนโค้ดดาวน์โหลด
รูปมาเก็บเองทุกครั้งที่ build และเว็บจะพังเงียบๆ เมื่อ Notion เปลี่ยน API หรือเมื่อหน้าถูกย้าย
เจ้าของเว็บให้น้ำหนักกับ "ระบบที่ไม่พังเองตอนไม่ได้แตะมา 6 เดือน" มากกว่าความสะดวกในการย้ายครั้งเดียว

## Consequences

- เครื่องมือที่ใช้เขียนเป็นเรื่องของผู้เขียนล้วนๆ (VS Code, Cursor, Obsidian หรืออะไรก็ได้)
  เว็บไม่รับรู้และไม่ผูกกับตัวใดตัวหนึ่ง
- ไม่มีหน้า admin สำหรับเขียนบนเว็บ ซึ่งเป็นการแลกโดยตั้งใจ เพราะมีผู้เขียนคนเดียว
