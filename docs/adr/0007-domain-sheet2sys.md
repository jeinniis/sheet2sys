# ใช้โดเมน sheet2sys.com ไม่ใช่ชื่อผู้เขียน

โดเมนสื่อถึงเส้นทางของผู้เขียนเอง คือจาก Google Sheet ไปสู่ระบบจริง ซึ่งเป็นสิ่งที่เว็บนี้เล่า
เราปฏิเสธโดเมนที่เป็นชื่อผู้เขียน (เช่น janesys.com) แม้จะสั้นกว่า เพราะชื่อคนที่ยังไม่มีใครรู้จัก
ต้องใช้เวลาหลายปีกว่าจะมีความหมาย ขณะที่ชื่อที่เล่าเรื่องได้มีความหมายตั้งแต่วินาทีแรกที่คนเห็น

ชื่อผู้เขียนยังคงปรากฏบนของทุกชิ้นและในหน้า About เพื่อความน่าเชื่อถือ แต่ไม่ผูกกับโดเมน
ซึ่งทำให้เว็บเปิดรับผู้เขียนคนอื่นหรือขยายเป็นอย่างอื่นได้ในอนาคตโดยไม่ต้องย้ายโดเมน
และการย้ายโดเมนคือการทิ้งความน่าเชื่อถือที่สะสมมาทั้งหมด จึงต้องเลือกให้จบตั้งแต่ต้น

## ทางเลือกที่พิจารณาแล้วไม่ได้ใช้

ระหว่างทางมีการเสนอชื่อแนว simplysys ซึ่งสื่อปรัชญา "แก้ปัญหาแบบเรียบง่ายและเงียบ"
และมีข้อดีคือไม่ผูกกับสเปรดชีต จึงรองรับหมวดที่ไม่เกี่ยวกับ Sheet ได้ดีกว่า
แต่ชื่อนี้ถูกจองไปแล้วทุก TLD ที่ใช้ได้จริง และชื่อทิศทางเดียวกันที่ยังว่างล้วนอ่อนกว่ามาก

ข้อสรุปคือโดเมนทำหน้าที่ให้คนจำได้ ส่วนปรัชญาให้ไปอยู่ในสโลแกน ซึ่งเปลี่ยนได้ตลอดเวลาโดยไม่มีต้นทุน
sheet2sys เป็นชื่อที่เล่า "เส้นทาง" ไม่ใช่ "หัวข้อ" หมวดที่ไม่เกี่ยวกับสเปรดชีตโดยตรง
เช่น พื้นฐานการเขียนโค้ดและวิธีคิด จึงยังมีที่ทางในชื่อนี้ ในฐานะสิ่งที่เก็บได้ระหว่างทาง
