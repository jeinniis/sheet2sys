# เปลี่ยนชื่อแบรนด์เป็น DotStack (supersedes ADR 0007)

ชื่อเว็บเปลี่ยนจาก sheet2sys เป็น DotStack ครอบคลุม UI, page title, CONTEXT.md, และ package name
ADR 0007 เคยเลือก sheet2sys เพราะชื่อเล่าเส้นทาง "จาก Google Sheet ไปสู่ระบบจริง" — decision
นั้นยังคงถูกบันทึกไว้เป็นประวัติ (ไม่แก้ไขของเดิม) แต่ไม่ใช่ชื่อที่ใช้งานจริงอีกต่อไป

**ยังไม่ได้เปลี่ยน** (นอกขอบเขตของ ADR นี้ — ดูเหตุผลด้านล่าง):

- GitHub repo ยังชื่อ `jeinniis/sheet2sys` เพราะเปลี่ยนชื่อ repo กระทบ URL ที่แชร์ไปแล้ว
  (issue links, git remote ของคนอื่นถ้ามี) เป็นการตัดสินใจที่ควรแยกจากการเปลี่ยนชื่อแบรนด์
- โดเมน `dotstack.com` **ยังไม่ได้เช็คว่าว่างหรือซื้อ** — `astro.config.mjs` ใส่ไว้เป็น placeholder
  ก่อน ต้องเช็คความพร้อมของโดเมนจริงก่อนจะยึดเป็นทางการ (ย้อนกลับดูเหตุผลของ ADR 0007 เรื่อง
  "การย้ายโดเมนคือการทิ้งความน่าเชื่อถือที่สะสมมาทั้งหมด" — ครั้งนี้ยังไม่มีอะไรให้ทิ้งเพราะยังไม่ publish
  ภายใต้โดเมนไหนจริงจัง จึงเป็นจังหวะที่เปลี่ยนได้โดยต้นทุนต่ำที่สุดแล้ว)

ผลข้างเคียงที่ดี: เพราะ URL เป็น `/{category}/{slug}` ไม่มีชื่อแบรนด์ปนอยู่ (ADR 0010) การเปลี่ยน
ชื่อแบรนด์ครั้งนี้จึงไม่กระทบ URL ของเนื้อหาแม้แต่เส้นเดียว
