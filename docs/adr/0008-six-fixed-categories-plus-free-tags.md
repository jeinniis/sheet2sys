# หกหมวดหมู่ตายตัว บวกแท็กอิสระ

ของทุกชิ้นอยู่ในหมวดหมู่เดียวจากหกหมวดที่กำหนดไว้ตายตัว และติดแท็กได้ไม่จำกัด
หมวดหมู่คือโครงกระดูกที่ใช้ทำเมนูและบอกเครื่องมือค้นหาว่าคลังนี้เชี่ยวชาญด้านใด
ส่วนแท็กคือเส้นเลือดที่ใช้เชื่อมโยงข้ามเนื้อหาโดยไม่ต้องขออนุญาตใคร

หมวดหมู่ปรากฏใน URL จึงเปลี่ยนภายหลังได้ยาก เราจึงเลือกให้มีน้อยและกว้างพอจะทนสามปี
เราปฏิเสธการใช้แท็กอย่างเดียวโดยไม่มีหมวด เพราะเมื่อแท็กเกินห้าสิบอันจะกลายเป็นความมั่ว
และปฏิเสธหมวดหมู่ซ้อนหลายชั้น เพราะผู้เขียนคนเดียวไม่มีวันได้ประโยชน์จากความลึกนั้น

แนวคิดเรื่อง "วิธีคิด" กับ "การข้ามข้อจำกัดของตัวเอง" ถูกรวมไว้ในหมวด Thinker หมวดเดียว
แม้ในทางทฤษฎีจะเป็นคนละเรื่อง เพราะในทางปฏิบัติทั้งสองเรื่องจะปรากฏในเนื้อหาชิ้นเดียวกันเสมอ
และการแยกออกเป็นสองหมวดจะทำให้ทั้งคู่ว่างเปล่าในช่วงปีแรก
