# ฝากเว็บที่ Cloudflare Pages ไม่ใช่ Vercel

แม้เจ้าของเว็บจะคุ้นเคยกับ Vercel จากโปรเจกต์ก่อนหน้า แต่เราเลือก Cloudflare Pages
เพราะ Vercel แพลนฟรีจำกัด bandwidth ที่ 100GB ต่อเดือนและห้ามใช้เชิงพาณิชย์ตามเงื่อนไขบริการ
ซึ่งจะบังคับให้ต้องจ่ายราว $20 ต่อเดือนทันทีที่เว็บเริ่มมีรายได้หรือสปอนเซอร์
ขณะที่ Cloudflare Pages ให้ bandwidth ไม่จำกัดและใช้เชิงพาณิชย์ได้บนแพลนฟรี

ข้อกำหนดตั้งต้นคือค่าโฮสต์ 0 บาทและต้องต่อยอดได้ในระยะยาว Cloudflare Pages เป็นตัวเลือกเดียว
ที่ไม่มีเพดานซึ่งจะบังคับให้ต้องจ่ายในวันที่เว็บประสบความสำเร็จ
